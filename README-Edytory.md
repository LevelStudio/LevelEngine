# LevelEngine CMS 2.3.0 — edytory tekstu

Wpisy (Newsy, konkursy, wydarzenia, changelog i ogłoszenia) i podstrony mają wspólny edytor wizualny: pogrubienie, kursywa, podkreślenie, przekreślenie, wyrównanie do lewej/środka/prawej i justowanie, nagłówki H2/H3, akapity, listy, cytaty, kod, linki, cofanie i usuwanie formatowania. Obrazki można wgrać lub wybrać z biblioteki; wymaga to uprawnienia zarządzania mediami.

Przycisk „Kod / wizualny” przełącza między kodem HTML i widokiem tekstu. Markdown pozostaje osobnym formatem; przyciski obsługują dostępne w nim elementy. Zmiana formatu HTML/Markdown nie konwertuje automatycznie istniejącej treści — używaj jej przy tworzeniu nowego tekstu. Oba formaty działają również w podstronach.

„O mnie” i sygnatura mają proste formatowanie przyciskami: [b], [i], [u], [s], [left], [center], [right]. Podgląd profilu po zapisaniu pokazuje efekt. Limity 1000/500 znaków obejmują znaczniki. Dotychczasowy zwykły tekst nadal działa; surowy HTML jest wyświetlany jako tekst.

Zajawki i SEO zachowują zwykły tekst i otrzymują licznik znaków. Edytor CSS ma licznik, wyłączone sprawdzanie pisowni i wcięcie czterema spacjami po Tab. Konfiguracja LevelBridge pozostaje tylko do odczytu.

## Aktualizacja

1. Wykonaj kopię plików i bazy danych.
2. W PA → Aktualizacje wgraj UPGRADE pasujący do obecnej wersji (2.2.0, 2.1.0 lub 2.0.1).
3. Odśwież panel, aby pobrał nowe skrypty. Sprawdź zapis wpisu i podstrony.

FULL-INSTALL służy do nowej instalacji. Paczki starszych aktualizacji obejmują także Media Uploader i LevelBridge. Nie nadpisują przesłanych plików, konfiguracji instalacji ani kopii zapasowych.

Sprawdzone lokalnie: zapis HTML i Markdown podstron, wyrównanie i bezpieczeństwo treści, pogrubienie/kursywa/wyśrodkowanie oraz biblioteka obrazków w przeglądarce i odczyt po zapisaniu. Wdrożenie na hosting nie zostało wykonane.
